# Earnly Design Lab

This is a public visual-reference repository, not the production app.

- Read `DESIGN-BRIEF.md`, `COBERTURA.md` and `PROMPT-CLOUD.md` before work.
- Preserve the original images in `screens/`, `screens.json`, `TOKENS-BASE.json` and `SHA256SUMS`. Build prototypes separately in `prototype/`.
- Use synthetic fixtures only. Never add real journeys, addresses from users, stores, backups, logs, credentials or private production code.
- Do not implement a backend, distance/tax engines, sensors, remote map services, accounts or payment systems. This task concerns presentation and demo interaction.
- Browser results do not prove native iOS behavior. Clearly label approximations and unavailable tests.
- Keep shared tokens and reusable components. Maintain a recoverable HANDOFF as phases finish.
- Do not deploy, change repository visibility, rewrite history or integrate into the real Earnly app.
